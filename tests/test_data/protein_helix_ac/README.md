# Helix A/C protein fixture

The suite's only non-lipid real-data coverage of `topology/cgmap.py`. A real
two-chain protein starting structure plus the three residue-level CG mappings
that the trajmap acceptance runs used.

## Provenance

| Field | Value |
|---|---|
| Source structure | `md_start.pdb`, staged root for `helix_0_AC_protein` (see catalog entry below) |
| Source mappings | `experiments/debug_cgmap/inputs/prot_{1res,2res,4site}_map.yaml` |
| Extraction date | 2026-08-10 |
| Generating script | `scripts/extract_test_fixtures.py --system protein_helix_ac` |
| Catalog entry | `data/catalog.yaml` → `helix_0_AC_protein` |

## Contents

`md_start.pdb` — 1687 atoms, chains A and C, 99 residues. **Copied whole, not
sliced.** At 133 KB it is already smaller than a cut-down version would be
worth, and slicing a protein mid-chain would break exactly the residue and
linker semantics these mappings exist to exercise.

`prot_1res_map.yaml`, `prot_2res_map.yaml`, `prot_4site_map.yaml` — the three
residue-level mappings, copied unmodified from
`experiments/debug_cgmap/inputs/`. They were generated by this project's own
`cgmap_builder` (see the `.provenance.json` beside each source file, which
stays in `experiments/` because it records run metadata rather than test
input). Between them they cover one-site-per-residue, two-residues-per-site,
and four-sites-per-residue, including the HSD/HSE histidine protonation states
and the linker-angle option.
