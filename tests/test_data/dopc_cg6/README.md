# DOPC 6-site CG fixture

Five real frames of the canonical REM / CD-REM working system, plus the
topology and tabulated forcefield needed to drive them through the production
kernels. Committed and shipped with the test suite so the numerical tests run
for anyone who clones this repository, with no access to the private working
data under `data/`.

## What was kept, and what was changed

`cg6_patch.data` — 96 whole lipids (576 sites, 480 bonds, 480 angles) cut from
the 1152-lipid source. The lipids are those whose head-group (HG) site lies
within 32 Å of the periodic corner of the box, measured under the minimum-image
convention, evaluated on frame 0.

* The **box is the real box** of the source frame, 196.25 × 196.25 × 73.20 Å,
  orthorhombic, fully periodic.
* Choosing the corner rather than the middle of the box is the point of the
  fixture: about 40% of the sub-cutoff pairs inside the patch are separated by
  a box boundary. A dropped or wrong minimum image is therefore a large,
  unmissable error rather than a rounding difference.
* Local packing is realistic — median nearest-neighbour distance 5.1 Å,
  roughly 143 neighbours per site inside the 25 Å pair cutoff — because the
  patch is spatially compact rather than a uniform dilution of the source. The
  patch spans both leaflets in z.
* Lipids are kept **whole**, so every bond and angle instance is intact. All 4
  atom types, all 3 bond types and all 3 angle types are present.
* Atom, bond and angle **instance ids** are renumbered contiguously from 1;
  molecule ids are renumbered 1–96. Atom types, bond types, angle types and
  masses are untouched.
* Coordinates are the unwrapped (`xu yu zu`) coordinates of frame 0, so
  molecules straddling a boundary are not broken.

`cg6_patch.lammpstrj` — the same 576 sites over the 5 frames, carrying every
column the source dump carries: `id type xu yu zu fx fy fz`. The forces are the
mapped all-atom reference forces already present in the source trajectory, so
this fixture serves force-matching tests as well as energy-side ones.

`ff/` — the real REM-init tabulated forcefield (`system.init`,
`system.settings`, and the 10 pair / 3 bond / 3 angle tables). The tables are
**thinned onto a coarser but still uniform grid spanning the identical
coordinate range**: pairs 2500 → 358 points over [0.01, 25.0] Å, bonds
499 → 250, angles 361 → 181. No value was recomputed, interpolated or refitted;
rows were dropped at a fixed stride chosen so both endpoints survive and the
spacing stays uniform, which is what LAMMPS and the AceCG table reader both
require. This keeps the whole fixture tree under half a megabyte.

## Rules for tests that use this

* Load it through the production path — `MDAnalysis.Universe` →
  `collect_topology_arrays` → `compute_pairs_by_type` → `compute_frame_geometry`
  → `energy` / `force` — not by hand-building `FrameGeometry`.
* Never read `data/` or `experiments/` from a test. Add to this fixture, or cut
  a new one with the script, instead.
* Pinned numbers in tests are regenerated by re-running the test with the
  pinning helper, not by editing the expected value until it passes. A pinned
  value that changes is a finding, not a maintenance chore.
